
# Recommendation System Project

This project focuses on building a recommendation system that predicts the top 20 most relevant items for each user by using the following algorithms: Item-Based Collaborative Filtering, Matrix Factorization, and Neural Collaborative Filtering.

## Project Structure

- `models/` folder: contains the models (.h5 files) of the algorithms.
- `output/` folder: the output files generated by the algorithms.
- `item_based_knn.py`: Item-Based Collaborative Filtering algorithm.
- `matrix_factorization.py`: Matrix Factorization algorithm.
- `neucf_recommendations.py`: Neural Collaborative Filtering algorithm.
- `requirements.txt`: required dependencies.
- `README.txt`: prject structure and guidance on how to run the code.

## How to Run the Code

Make sure that we have Python 3.12 installed on our system. Also, make sure that we have the following dependencies installed: tensorflow==2.16.1, pandas, numpy, tqdm, implicit, and scipy.
1. Clone this repository

```text
git clone https://github.com/tritinpho/cmpe256-recommneder-system.git
```

2. Navigate to the project folder

```text
cd cmpe256-recommneder-system
```

3. Create a virtual environment with Python 3.12

```text
python3.12 -m venv venv
```

4. Activate the virtual environment on Windows using CMD:

```text
venv\Scripts\activate.bat
```

5. Install the required dependencies:

```text
pip install -r requirements.txt
```

6. Run recommendation algorithm script:

```text
python item_based_knn_youngsuh.py
```

or

```text
python matrix_factorization.py
```

or

```text
python neucf_recommendations.py
```

7. Navigate to the `models/` folder to find the saved models and the `output/` folder to find the output files that contain the top 20 recommended items for each algorithm.
